# Full-Stack Engineer #2 — Mizan  ·  Fully remote

**The role.** Second engineering hire after the senior backend lead. You're the bridge between backend data pipelines and the consumer-facing experience. Significant React Native focus as the mobile app launches.

## What you'd ship in your first 90 days

- **Mobile app v1 (iOS + Android).** React Native shell on top of the existing web engine. Native feel for the screening flow.
- **In-app onboarding.** "Pick your scholar" flow, brokerage connection, first stock screen — measured against funnel conversion.
- **Search infrastructure.** Fast ticker autocomplete with cached fundamentals. Sub-100ms p99.
- **Settings / account / billing pages.** Stripe + RevenueCat wiring.

## Stack

- TypeScript end-to-end. Next.js (web), React Native + Expo (mobile), Node.js backend.
- Tailwind for web, NativeWind for mobile (shared design tokens).
- Plain for support, PostHog for analytics, Mixpanel for funnels.

## Who I'm looking for

- 3-5 years full-stack experience, ideally including consumer mobile.
- Has personally shipped a paid app on iOS or Android — knows the App Store and Play Store review processes from experience, not from blog posts.
- Strong React + React Native. Comfortable in Node.js.
- Pragmatic about scope. "Good enough to ship" > "polished and missed Tuesday."
